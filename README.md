# Hellscape CAPTCHA Compilation

A collection of deliberately terrible CAPTCHA designs.

| CAPTCHA | Description |
| --- | --- |
| [Letter Match](letter-match/) | Find 6 characters in a physics pile of ~160, then drag them onto a line in the right order, case and orientation. Includes a trash bin you can pour back out. |

Each CAPTCHA is a standalone `index.html`. Open it in a browser (internet needed for the physics library).
